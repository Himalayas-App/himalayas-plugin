description: Show new Himalayas job matches for my profile since the last check.
---

Use the `find-remote-jobs` skill and call `get_new_matches` to show jobs matching the user's Himalayas profile posted since an agent last checked.

For each match give the title, company, link, where it is open to, salary if listed, and one line on fit. Offer to save the best ones, or skip the ones the user passes on with a reason. Change nothing without the user's yes.
