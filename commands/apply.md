Use the `apply-to-jobs` skill to prepare an application.

Job: $ARGUMENTS

1. Check fit against the user's profile and point out anything that rules the job out.
2. Documents: on Plus, offer a tailored resume and cover letter. On Free, say the account gets one of each, ever, and make them only if the user wants them for this job. If they are used up, pass on the tool's Plus note once and continue with the user's own resume.
3. Draft answers to likely application questions from the user's saved answers.
4. When the user decides to apply, give the employer's apply link. This works on every plan. The user submits the application themselves.
