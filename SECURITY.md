# Security

Please report security issues to hi@himalayas.app with "Security" in the
subject, rather than opening a public issue. Include the steps to reproduce
and the impact. We aim to reply within two working days.

This plugin contains only Markdown skills, commands and manifests. It runs no
code; every request goes to the hosted Himalayas MCP server at
`https://mcp.himalayas.app/mcp`.
